# Privacy Policy

## Data Collection

We collect email, password (hashed), and chat messages for providing support services.

## Data Usage

Data is used solely for user authentication and support interactions.

## Data Retention

User data is retained for 2 years after account deactivation.

## Data Security

Passwords are hashed with bcrypt. Communications are encrypted.

## User Rights

Users can request data deletion by contacting support.

## Contact

For privacy concerns, email privacy@helpsync.com.
